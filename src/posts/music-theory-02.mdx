# 音的分组

## 科学音调记号法（Scientific pitch notation）

上篇文章提到：我们可以用 A0, A1, A2……这样的方式来区分不同组的 A。这种记号就叫做**科学音调记号法**。

这种记号法的具体规则如下：

- 钢琴上从左边数第一个 C 键称为 C1，第二个称为 C2，以此类推；
- 每个音由**音名加编号**的形式表示，**音名为大写**；
- 最低可以表示到第零组，第零组在钢琴上只有 A0 ♯A0 B0 这三个键，更低的音用该记号法无法表示，但这些音也极少使用。

btw，C0 的频率已经低于 20 Hz 了。有些人可能会疑惑：这些音不是次声波吗，人耳是不是听不到？实际上，当我们弹奏 C0 这个音时，虽然听不到那个低于 20 Hz 的基音，但是可以听到它的**泛音**，也就是基频的整数倍频率，所以我们还是可以感知到这些音的，它们还是有存在的意义的——不过确实很少很少用就是了。

## 赫尔姆霍茨音调记号法（Helmholtz pitch notation）

这种记号法将钢琴的第三个组（最左侧不完整的也算一组），也就是 C2 D2……这些音所在的组称为**大字组**，大字组右侧的第四个组，也就是 C3 D3……这些音所在的组称为**小字组**。大字组左侧依次为大字一组（C1 所在的组）、大字二组（A0 所在的组）……小字组右侧依次为小字一组（C4 所在的组）、小字二组（C5 所在的组）……以此类推。

![赫尔姆霍茨音调记号法的分组](../assets/images/illustrations_posts/music-theory-02/helmholtz-pitch-notation.avif)

在表示某个音时，具体规则如下：

- **大字组的音直接用音名的**大写字母**表示，如 C D；**小字组**的音名直接用音名的**小写字母**表示，如 c d；
- **大字 N 组**的音在音名**大写字母**的右下角加一个**数字下标**，如大字一组的 C 表示为 C<sub>1</sub>，大字三组的 A 表示为 A<sub>3</sub>；
- **小字 N 组**的音在音名**小写字母**的右上角加一个**数字上标**，如小字二组的 E 表示为 e<sup>2</sup>，小字四组的 B 表示为 b<sup>4</sup>。

## 中央 C 与标准音

这里还要介绍两个比较重要的音：**中央 C** 和**标准音**。

**中央 C** 是位于钢琴中央的那个 C，也就是 C4 或 c<sup>1</sup>，这是比较常用的一个 C。**标准音**则是 A4 或 a<sup>1</sup>，这个音的频率是 440 Hz。

# 高音点与低音点

在简谱上，如何区分不同组的音呢？以 1=C 为例，首先我们要知道，这个默认的 1 通常对应的是小字一组的 C，因为人能唱出来的音就在小字一组附近。

那么如果要表示比小字一组低一组的音（小字组），就要在这个音的正下方加一个点，称之为**低音点**；如果低两组（大字组）就在正下方加两个点，称为**倍低音点**；如果更低，则继续加三个点、四个点……同理的，如果高一组（小字二组），就在音的正上方加一个点，称之为**高音点**；高两组（小字三组）就在正上方加两个点，称之为**倍高音点**；如果更高，就继续加三个点、四个点……~~加这么多点别给歌手给唱死了~~

# 音域

所谓**音域**，就是指某个乐器能发出的**最低音到最高音的范围**。

例如，钢琴能发出的最低音是 A0，最高音是 C8，因此钢琴的音域就是 A0 - C8。小提琴能发出的最低音是 G3，没有明确的最高音，大概是 B7，那么小提琴的音域就是 G3 - B7。人声的音域通常认为在 G3 - D5，~~所以多加俩高音点低音点很容易就把歌手唱死了~~，这是对于大部分人而言，不同人的音域会存在差异，比如男低音的音域会低很多，女高音的音域则会高很多。

# 半音与全音

**半音**与**全音**指的是两个音之间的**距离**，而不是指某一个音。

**半音**是基础乐理中两个音之间距离的**最小单位**，钢琴上两个相邻的键相差的就是一个半音（注意黑键也要算在其中，C4 和 D4 并不相邻，因为它们之间相隔了一个黑键 ♯C4）。例如我们可以说：E4 到 F4 是一个半音的距离，或者直接说 E4 到 F4 是半音。同理有 ♯F5 到 G 是半音、♭D6 到 D6 是半音、C7 到 B6 是半音……注意半音仅指距离而**没有方向**，我们既可以说 B6 到 C7 是半音，也可以说 C7 到 B6 是半音。

**全音**则是指**两个半音**，在钢琴上，中间隔了一个键的两个音之间就是一个全音的距离。例如 C4 到 D4 是全音、♯D4 到 F4 是全音、♯F5 到 E5 是全音……同样地，全音没有方向。

:::info
这里我们以钢琴作为例子解释了半音与全音，事实上在任何乐器中都是如此。
:::

# 乐音与噪音

**乐音**是指**振动规则、频率稳定**的音。按下钢琴的一个按键，发出的声音始终保持在一个频率，这就是乐音。

**噪音**是指**振动不规则、频率杂乱**的音，这与我们日常生活中所说的噪音有所不同：此处所说的噪音没有贬义，而且它不一定是吵闹的，比如树叶的沙沙声也是噪音，因为其频率不规则。再比如，架子鼓发出来的也是噪音。

音乐往往是**乐音和噪音的结合**，并不是说音乐中只能有乐音而不能有噪音。像架子鼓这样的噪音乐器也可以是乐曲的一部分。

音乐中使用到的所有乐音的总和被称为**乐音体系**，有一种说法是乐音体系共有 88 个音，即钢琴的 88 个键。不过还有其他的说法，但由于该概念并不重要，故此处不再赘述。

# 音级

**乐音体系中的每个音**，都叫**音级**。音级又可以分为**基本音级**和**变化音级**，基本音级就是不带有任何升降记号的音级，一共七个：CDEFGAB；而变化音级就是带有升降号的音级，包括升音级、降音级重升音级、重降音级，每种包含七个。

虽然 E 和 ♭F 是等音，但是前者是基本音级，而后者是变化音级，因为前者没有升降号而后者有降号。其余音也同理，只要带有升降号，就是变化音级，无论它是否与某个基本音级为等音。

:::info
本文省略了音列、自然半音、变化半音、自然全音、变化全音的介绍，因为它们很不重要，如有兴趣可以了解。
:::

# 总结

这篇文章我们接触了好几组概念，看起来有点多，但其实它们都围绕着同一个核心问题：音乐里的音，到底是怎么组织和命名的？

我们从"如何区分不同高低的同一个音名"出发，认识了科学音调记号法（C4、A0 这种）和赫尔姆霍茨记号法（D<sub>1</sub>、e<sup>2</sup>这种），然后了解了钢琴正中间的中央 C 到底是哪一个，以及那个被全世界当作调音基准的标准音 A4 = 440 Hz。接着我们把这些分组规则映射到简谱上，理解了高音点和低音点是怎么一回事。

有了"哪个音在哪"的基础，我们开始聊音和音之间的关系：半音是相邻键的距离，全音是隔一个键的距离，而且这个距离没有方向，只表示远近。然后我们又区分了乐音和噪音——乐音是频率稳定的声音，而噪音不是指吵闹的声音，是指振动不规则的声音，音乐里两者都会用到。最后，我们进入了乐音体系内部，认识了音级这个概念：不带升降号的是基本音级，带了的就是变化音级，哪怕它是某个基本音级的等音，只要挂着升降号就归到变化音级那边。
